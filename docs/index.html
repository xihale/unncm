01

它是什么

What & Why

网易云下载的歌，到手是一个 .ncm——文件是你的，打开方式不是。 unNCM 把它还原成标准音频，标签、歌词、封面一并补齐。 之后任何播放器、任何设备，都能直接听。

晴天.ncm ⟶ 晴天.flac · 44.1kHz · 周杰伦

* 解密在本地离线完成；仅标签、歌词、封面的补全会访问网易云公开接口。

02

曲目单

Tracklist

Side A — 性能

A1 流式解密 NCM 头解析与流式解密都在 Rust 层完成，边读边写，不把整个文件装进内存。 Rust / JNI
A2 并发转换 线程数 1–8 可调；扫描与转换流水线并行，整张歌单一轮跑完。 Coroutines × N
A3 元数据补全 查询网易云接口，把标题、艺术家、专辑写回音频标签。 NetEase API
A4 歌词与封面 可选嵌入歌词与封面，任何播放器都能显示完整信息。 LRC / Cover

Side B — 体验

B1 双入口导入 选整个文件夹，或多选散装文件；都走系统文件选择器（SAF）。 SAF
B2 会话恢复 上次选的目录和待处理列表会保留；中途退出，重开接着转。 Persistent URI
B3 极简界面 一屏列表，无顶栏；不要的曲目向左一划。Material 3 深色。 Compose / M3
B4 完全开源 代码在 GitHub，MIT 许可；随便看，随便改，自己编译也行。 MIT License
03

怎么用

Usage
壹

选择文件

选文件夹或多选 .ncm 都行；文件夹选择器默认打开网易云的下载目录，不用自己翻。

贰

开始转换

1–8 线程并发解密，进度实时显示；不想要的曲目，向左划掉即可。

叁

取回音乐

解好的文件在原目录的 unlocked 文件夹里：mp3 / flac，标签、歌词、封面都已写入。
